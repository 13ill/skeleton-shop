## Key Features for Store Pages

### Home Page
1. **Hero Section** - ข้อความที่ดึงดูด + CTA button
2. **Featured Products** - สินค้าแนะนำ (grid layout)
3. **Categories** - หมวดหมู่สินค้า (horizontal scroll หรือ grid)
4. **New Arrivals** - สินค้าใหม่
5. **Testimonials** - รีวิวลูกค้า (carousel)
6. **Newsletter** - สมัครรับข่าวสาร (email input)
7. **Footer** - Social links, contact info, copyright

### Products Page
1. **Filter Sidebar** - กรองตาม category, price, material
2. **Sort Options** - เรียงตาม price, name, new
3. **Product Grid** - แสดงสินค้า (grid 3-4 columns)
4. **Pagination** - แบ่งหน้า
5. **Quick View** - ดูข้อมูลสินค้าเบื้องหน้า (modal)

### Product Detail Page
1. **Product Images** - Gallery (carousel)
2. **Product Info** - Name, price, description
3. **Specifications** - Material, size, weight
4. **Add to Cart** - Button
5. **Related Products** - สินค้าที่เกี่ยวข้อง
6. **Reviews** - รีวิว (stars + comments)

### Contact Page
1. **Store Info** - Brand name, tagline, address
2. **Opening Hours** - เวลาทำการ
3. **Contact Channels** - Social links, phone, email
4. **QR Code** - LINE QR code
