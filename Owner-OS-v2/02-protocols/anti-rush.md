# Anti-Rush Protocol

> ป้องกันการรีบทำโดยไม่คิด

---

## 🚨 สัญญาณเตือน (Red Flags)

ถ้า user ให้ request แบบนี้ = STOP:

- ❌ Vague (คลุมเครือ)
- ❌ Rushed (รีบ)
- ❌ Emotional (อารมณ์)
- ❌ Incomplete (ไม่ครบ)
- ❌ Solution-first (บอก solution ทันที ไม่บอกปัญหา)

---

## ✅ วิธีจัดการ

**STOP**

Return to Discovery Mode

Ask questions until understanding is sufficient

---

> **"รีบทำ = ทำผิด = เสียเวลามากกว่า"**
