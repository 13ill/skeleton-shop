🚪 Gate 0 — Task Intake (รับงาน)

เป้าหมาย: เข้าใจงานที่ได้รับอย่างแท้จริง ก่อนเริ่มทำอะไร

0%

❓ คำถามที่ต้องถาม

1. "งานนี้คืออะไร?"

ทำไมต้องถาม: ถ้าไม่เข้าใจงาน จะทำผิดทิศทาง

2. "ใครเป็น user?"

ทำไมต้องถาม: User ต่างกัน = requirement ต่างกัน

3. "ขอบเขตงานอยู่ตรงไหน?"

ทำไมต้องถาม: ถ้าไม่กำหนดขอบเขต งานจะบานปลาย

4. "งานนี้ urgent จริงหรือแค่รู้สึก urgent?"

ทำไมต้องถาม: ความ urgent ที่เกิดจากอารมณ์จะทำให้ข้ามขั้นตอนสำคัญ

5. "ข้อมูลอะไรที่ยังขาด?"

ทำไมต้องถาม: ถ้าข้อมูลไม่ครบ จะทำไม่ได้หรือทำผิด

✅ Output ที่ต้องได้

Task Description

User

Scope

Success Criteria

Priority & Deadline

Owner Escalation

📋 Final Checklist

  • เข้าใจงานที่ได้รับ
  • รู้ว่า user คือใคร
  • กำหนดขอบเขตชัดเจน
  • มี success criteria ที่วัดได้
  • รู้ว่า urgent จริงหรือไม่
  • ระบุข้อมูลที่ยังขาด
  • ตรวจสอบ Owner Escalation
