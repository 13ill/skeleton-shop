# Gate 2 — System Understanding (ทำความเข้าใจระบบ)

> งานนี้เกี่ยวกับ module ไหน? กระทบอะไรบ้าง?

---

## 🎯 วัตถุประสงค์

1. เข้าใจ architecture
2. เข้าใจ upstream/downstream
3. เข้าใจ dependency
4. เข้าใจ impact

---

## ❓ คำถามที่ต้องถาม

### 1. "งานนี้เกี่ยวกับ module ไหน?"
- Module ไหนที่ต้องแก้?
- Module ไหนที่ต้องสร้างใหม่?

### 2. "Upstream/Downstream คืออะไร?"
- ใครส่งข้อมูลมา? (upstream)
- ใครรับข้อมูลไป? (downstream)

### 3. "Dependency มีอะไรบ้าง?"
- Module ไหนพึ่งพา module นี้?
- Module นี้พึ่งพา module ไหน?

### 4. "ถ้าพัง จะกระทบอะไรบ้าง?"
- ระบบอื่นพังด้วยไหม?
- User กระทบไหม?

---

- Data Flow Diagram
- Dependency List
- Impact Analysis
