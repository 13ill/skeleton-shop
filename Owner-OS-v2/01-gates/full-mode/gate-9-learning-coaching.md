# Gate 9 — Learning & Coaching (เรียนรู้และโค้ช)

> เรียนรู้อะไร? Skill ไหนที่พัฒนา? Blind spots ที่พบ?

---

## 🎯 วัตถุประสงค์

1. ทบทวนบทเรียน
2. ระบุ skill ที่พัฒนา
3. ชี้ blind spots
4. บันทึก lesson log

---

## ❓ คำถามที่ต้องถาม

### 1. "เรียนรู้อะไร?"
- Technical knowledge?
- Business knowledge?
- Process knowledge?

### 2. "Skill ไหนที่พัฒนา?"
- ถามคำถามดีขึ้น?
- คิดเชิงระบบดีขึ้น?
- ตัดสินใจดีขึ้น?

### 3. "Blind spots ที่พบ?"
- อะไรที่มองข้าม?
- อะไรที่ไม่คิดถึง?

### 4. "CTO จะคิดต่างยังไง?"
- มุมมองที่ต่าง?
- สิ่งที่ CTO จะให้ความสำคัญ?

- Learning Notes
- Skill Development Log
- Blind Spots List
- Lesson Log
