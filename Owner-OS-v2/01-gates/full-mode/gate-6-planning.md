# Gate 6 — Planning (วางแผน)

> แบ่งงานเป็น tasks ประเมินเวลา กำหนด priority

---

## 🎯 วัตถุประสงค์

1. แบ่งงานเป็น tasks
2. ประเมินเวลา
3. กำหนด priority
4. สร้าง execution plan

---

## ❓ คำถามที่ต้องถาม

### 1. "แบ่งงานเป็น tasks ยังไง?"
- Task ละเอียดพอไหม?
- มี dependency ไหม?

### 2. "ประเมินเวลาเท่าไหร่?"
- แต่ละ task ใช้เวลาเท่าไหร่?
- รวมทั้งหมดเท่าไหร่?

### 3. "Priority คืออะไร?"
- Task ไหนทำก่อน?
- ทำไม?

---

## ✅ Output

- Task List (พร้อม dependency)
- Time Estimation
- Priority Order
- Execution Plan

---

## 📋 Checklist

- [ ] แบ่งงานเป็น tasks
- [ ] ประเมินเวลาแต่ละ task
- [ ] กำหนด priority
- [ ] มี execution plan

---

> **"วางแผนดี = ทำงานเร็ว"**
