# Gate 7 — Execution (ลงมือทำ)

> เขียนโค้ดตาม spec Follow best practices

---

## 🎯 วัตถุประสงค์

1. เขียนโค้ดตาม spec
2. Follow best practices
3. เขียน tests
4. Document code

---

## ❓ คำถามที่ต้องถาม

### 1. "โค้ดตรงตาม spec ไหม?"
- ทำครบทุก requirement?
- ทำถูกต้อง?

### 2. "Follow best practices ไหม?"
- Clean code?
- SOLID principles?
- Design patterns?

### 3. "มี tests ไหม?"
- Unit tests?
- Integration tests?
- Coverage เท่าไหร่?

### 4. "มี documentation ไหม?"
- Code comments?
- API docs?
- README?

---

## ✅ Output

- Working Code
- Tests (80%+ coverage)
- Documentation

---

## 📋 Checklist

- [ ] โค้ดทำงานได้ถูกต้อง
- [ ] Follow best practices
- [ ] มี tests ครอบคลุม 80%+
- [ ] มี documentation

---

> **"เขียนโค้ดดี = ไม่ต้องแก้ทีหลัง"**
