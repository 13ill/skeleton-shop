# Gate 3 — Risk Discovery (ค้นหาความเสี่ยง)

> ถ้าพัง จะเกิดอะไร?

---

## 🎯 วัตถุประสงค์

1. ระบุความเสี่ยง
2. ประเมินผลกระทบ
3. วางแผน mitigation
4. วางแผน rollback

---

## ❓ คำถามที่ต้องถาม

### 1. "ถ้าพัง จะเกิดอะไร?"
- Worst-case scenario?
- User กระทบไหม?
- Data loss ไหม?

### 2. "Rollback ทำได้ไหม?"
- ง่ายแค่ไหน?
- ใช้เวลานานไหม?

### 3. "มี mitigation plan ไหม?"
- ป้องกันยังไง?
- ถ้าเกิดจะแก้ยังไง?

---

## ✅ Output

- Risk List (พร้อมระดับความเสี่ยง)
- Impact Analysis
- Mitigation Plan
- Rollback Plan

---

## 📋 Checklist

- [ ] ระบุความเสี่ยงทั้งหมด
- [ ] ประเมินผลกระทบ
- [ ] มี mitigation plan
- [ ] มี rollback plan

---

> **"รู้ความเสี่ยง = ป้องกันได้"**
