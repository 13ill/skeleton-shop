# Gate 4 — Solution Design (ออกแบบ Solution)

> มีกี่ทางเลือก? แต่ละทาง tradeoff คืออะไร?

**4W Framework:** Gate นี้ตอบคำถาม **HOW** (ทำยังไง) — ดู `02-protocols/4w-framework.md`

**⚠️ ห้ามมา Gate นี้ก่อนตอบ WHY (Gate 1) และ WHAT (Gate 0) ให้ครบ — อย่ารีบหา solution ก่อนนิยามปัญหา**

---

## 🎯 วัตถุประสงค์

1. เสนอ 2-3 ทางเลือก
2. วิเคราะห์ tradeoff
3. ออกแบบ architecture
4. เลือก tech stack

---

## ❓ คำถามที่ต้องถาม

### 1. "มีกี่ทางเลือก?"
- อย่างน้อย 2-3 ทาง

### 2. "แต่ละทาง tradeoff คืออะไร?"
- ข้อดี/ข้อเสีย
- ราคา
- เวลา
- ความซับซ้อน
- **Business Impact ของแต่ละทาง (ไม่ใช่แค่ technical) — ดู `06-references/business-impact-analysis.md`**

### 3. "Architecture design คืออะไร?"
- Module ไหนบ้าง?
- เชื่อมต่อกันยังไง?

### 4. "Tech stack คืออะไร?"
- ใช้ library/framework อะไร?
- ทำไมเลือกตัวนี้?

---

## ✅ Output

- 2-3 Solution Options
- Tradeoff Analysis
- Architecture Design
- Tech Stack (พร้อมเหตุผล)

---

## 📋 Checklist

- [ ] ตอบ WHY/WHAT ครบแล้วก่อนออกแบบ solution
- [ ] มี 2-3 ทางเลือก
- [ ] วิเคราะห์ tradeoff ครบ (รวม business impact)
- [ ] ออกแบบ architecture
- [ ] เลือก tech stack พร้อมเหตุผล

---
