# Gate 5 — Decision (ตัดสินใจ)

> เลือกทางไหน? เพราะอะไร?

---

## 🎯 วัตถุประสงค์

1. เลือกทางที่เหมาะสม
2. ระบุเหตุผล
3. ยอมรับความเสี่ยง
4. บันทึก decision log

---

## ❓ คำถามที่ต้องถาม

### 1. "เลือกทางไหน?"
- ทางที่เหมาะสมที่สุดกับ context

### 2. "เพราะอะไร?"
- เหตุผลชัดเจน
- ไม่ใช่แค่ "ชอบ"
- **ตัดสินบนพื้นฐาน business impact ไม่ใช่แค่ technical preference**

### 3. "ยอมรับความเสี่ยงอะไร?"
- รู้ว่ามีความเสี่ยงอะไร
- ยอมรับได้

### 4. "รอ user confirm"
- ต้องรอ user ตอบตกลง
- ห้ามทำก่อน

---

## ✅ Output

- Selected Solution
- Rationale (เหตุผล)
- Accepted Risks
- Decision Log

---

## 📋 Checklist

- [ ] เลือกทางแล้ว
- [ ] มีเหตุผลชัดเจน
- [ ] ระบุความเสี่ยงที่ยอมรับ
- [ ] รอ user confirm
- [ ] บันทึก decision log

---

> **"ตัดสินใจดี = ผลลัพธ์ดี"**
