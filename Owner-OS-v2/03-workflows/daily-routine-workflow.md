# Daily Routine Workflow

> กิจวัตรประจำวันสำหรับ AI-Native Developer

---

## 🌅 เช้า (9:00)

### 1. เปิด AI + โหลด context

```
"สวัสดี กลับมาทำงานต่อ"
```

AI จะ:
- เช็คงานค้าง
- แจ้งเตือน
- โหลด context
- พร้อมทำงาน

### 2. เปิด Master Checklist

```bash
open checklists/master-checklist.html
```

- ดูความคืบหน้า
- ดูงานค้าง
- วางแผนวันนี้

### 3. เลือกงาน

- งานค้างจากเมื่อวาน?
- งานใหม่?
- Bug ด่วน?

---

## 🏃 ระหว่างวัน (9:00-18:00)

### ทำงานตาม Workflow

1. **รับงาน** → เปิด HTML checklist
2. **ถามคำถาม** → ตาม checklist
3. **ผ่าน Gates** → เช็ค checklist
4. **บันทึก Decision** → ใช้ decision-log.html
5. **ทำงาน** → ใช้ AI ช่วย
6. **Review** → ตรวจสอบคุณภาพ

### ถ้าหยุดชั่วคราว

```
"หยุดก่อน ไปทำอย่างอื่นก่อน"
```

AI จะ:
- บันทึก checkpoint
- แจ้ง: "✅ บันทึกแล้ว"

### ถ้ากลับมาทำต่อ

```
"กลับมาทำงานเดิมต่อ"
```

AI จะ:
- อ่าน checkpoint
- สรุปสถานะ
- พร้อมทำต่อ

---

## 🌆 เย็น (18:00)

### 1. สรุปงานวันนี้

```
"สรุปงานวันนี้"
```

AI จะสรุป:
- ทำอะไรไปบ้าง
- ผ่าน gate ไหนบ้าง
- เรียนรู้อะไร

### 2. บันทึก Lesson

ถ้ามีบทเรียนสำคัญ:
- เปิด lesson-log.html
- บันทึกบทเรียน

### 3. อัปเดต Master Checklist

- เช็ค checklist ที่ทำเสร็จ
- บันทึกความคืบหน้า
- Export progress

### 4. วางแผนพรุ่งนี้

- งานค้างอะไรบ้าง?
- งานใหม่อะไรบ้าง?
- Priority คืออะไร?

---

## 📅 สัปดาห์ละครั้ง (ศุกร์ 17:00)

### Weekly Review

```
"ทบทวนสัปดาห์นี้"
```

AI จะสรุป:
- ทำอะไรไปบ้าง
- เรียนรู้อะไร
- Skill ไหนที่พัฒนา
- Blind spots ที่พบ

### อัปเดต Progress Tracker

- เปิด progress-tracker.html
- อัปเดตความคืบหน้า
- ดูว่าอยู่ phase ไหนของ roadmap

---

## 📆 เดือนละครั้ง (วันสุดท้ายของเดือน)

### Monthly Review

```
"ทบทวนเดือนนี้"
```

AI จะสรุป:
- อยู่ phase ไหนของ roadmap?
- KPI ถึงเป้าหรือยัง?
- ต้องปรับอะไร?

### Export Logs

- Export decision logs
- Export lesson logs
- Export progress report

## 💡 Tips

### สำหรับคนสะเพร่า

- ตั้ง alarm เตือน 9:00 (เริ่มงาน)
- ตั้ง alarm เตือน 18:00 (สรุปงาน)
- ใช้ Master Checklist ทุกวัน
- บันทึก decision ทุกครั้ง

### สำหรับคนที่ลืมง่าย

- เปิด Master Checklist ทิ้งไว้
- บันทึก checkpoint บ่อยๆ
- ใช้ AI เตือนงานค้าง
